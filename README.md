# Heaven Interiors — Architectural Couture & Spatial Design

A luxury architectural studio website and dynamic atelier content management system crafted for Heaven Interiors.

## Overview
- **Visual Design**: Warm ivory (`#F5F0E6`), deep charcoal (`#141414`), and architectural gold (`#C5A15B`) editorial aesthetic.
- **Cinematic Curtain Reveal**: GSAP ScrollTrigger-driven velvet drapery reveal with responsive mobile support and transparent navigation bar.
- **Interactive Features**: Dynamic filterable projects portfolio, materials tactile library, video showcase with theater mode, and interactive contact atelier dossier.
- **Atelier Administration**: Embedded client-side CMS (`/admin`) with full LocalStorage persistence for managing projects, services, materials, videos, and inquiries.

## Tech Stack
- Next.js (App Router, Turbopack)
- React 19 / TypeScript
- Tailwind CSS
- GSAP & ScrollTrigger
- Framer Motion
- Lucide React

## Getting Started
```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the client website, or [http://localhost:3000/admin](http://localhost:3000/admin) for the Atelier CMS.
